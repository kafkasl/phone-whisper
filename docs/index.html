How it works

  1. 1
    Tap or long-press the overlay button

    Tap once for your default preset, or long-press and slide onto a wide shortcut pill to switch language or toggle cleanup and screen context.

  2. 2
    Speak and watch live words appear

    Audio streams over WebSocket (while backing up locally to disk) and displays live words in the top bar.

  3. 3
    Tap stop or Done (or cancel anytime)

    Tap the red button again or Done in the top bar to finalize, or tap Cancel to abort cleanly.

  4. 4
    Optional context-aware polish

    When enabled on a shortcut, a fast OpenAI-compatible model fixes spelling, technical terms, and spoken self-corrections.

  5. 5
    Text is inserted cleanly

    The finished text goes straight into the focused Android input field, with clipboard fallback and offline retry if your connection drops.

Local or cloud — your choice

Both modes use your own hardware or your own API key. I run no backend.

Local mode

  • On-device transcription via sherpa-onnx
  • Audio never leaves your phone
  • No API key required
  • Automatic fallback if cloud credits run out

Cloud streaming mode

  • Real-time streaming via ElevenLabs Scribe v3 Live or Google Gemini Live
  • Your own API keys, stored privately on-device
  • Optional cleanup via any OpenAI-compatible endpoint (defaults to Gemini Flash-Lite)
  • Disk backup + inline retry if your connection drops
Requests go straight from your phone to your chosen provider. I'm not in the loop.

Why Accessibility permission is needed

Phone Whisper uses Android Accessibility Service only when you explicitly dictate: to insert dictated text into the currently focused field and—only on shortcuts where you enable screen context—to read visible non-password text so cleanup can fix names and jargon.

It does not replace your keyboard, log keystrokes, or run background automation.

The app is open source. You can read exactly what it does before granting the permission.

FAQ

Why not just make it a keyboard?

A custom keyboard means replacing your existing keyboard entirely. That's a lot of friction. Phone Whisper leaves your keyboard alone and works on top of any app, any keyboard.

Why does it need Accessibility permission?

Android doesn't have a standard API for inserting text into another app's focused field. Phone Whisper uses Accessibility only when you dictate—to insert text and, if enabled on that shortcut, read non-password screen context to improve names and technical terms.

Does audio stay on-device?

In local mode, yes. In cloud mode, audio streams directly from your device to ElevenLabs or Google Gemini using your own API key. I don't have a backend and never see your audio.

Does it work in every app?

It works in most apps with standard text fields. Some apps restrict text injection for security reasons, and others use custom text surfaces instead of normal input fields. In those cases, the transcribed text is copied to your clipboard as a fallback.

Is it on the Play Store?

Not yet. I'm shipping the APK directly first, tightening the experience, and deciding later whether a Play Store release makes sense.

Is this finished?

It's an open-source personal tool that I use daily and keep improving in public.
